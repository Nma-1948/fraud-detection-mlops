# Fraud Detection MLOps

A production-oriented machine learning project for detecting potentially fraudulent financial transactions.

The project will progressively cover:

- Fraud detection model development
- Model evaluation
- Prediction API
- Containerization with Docker
- CI/CD with GitHub Actions
- Amazon ECR image management
- Kubernetes deployment
- Prometheus monitoring
- Grafana dashboards
- Model versioning and MLOps workflows

## Project Goal

Build, deploy, monitor, and operate a lightweight fraud detection service using a cloud-native MLOps workflow.

## Development Workflow

Phone / Termux → GitHub → GitHub Actions → Amazon ECR → Kubernetes → Prometheus → Grafana
